# VERIFICATION_PLAN.md

## Plano de verificacao

### Testes manuais locais

1. Abrir `index.html` no navegador.
2. Digitar texto simples.
3. Confirmar que o texto aparece corretamente.
4. Digitar uma marcacao HTML simples.
5. Confirmar que a marcacao aparece como texto literal, nao como HTML renderizado.

### Resultado esperado apos patch

A aplicacao deve preservar funcionalidade e impedir interpretacao de HTML digitado pelo usuario.

### Evidencia publica

Publicar apenas descricao do achado, patch aplicado e verificacao.
Nao publicar dados locais sensiveis.
